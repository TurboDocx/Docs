## Overview

The Create Tag endpoint adds a new tag to your organization. Tags are a flat, organization-wide label set; once created, a tag can be attached to templates (with [Edit Template Metadata](/docs/API/edit-template-metadata)) or variables to make them easier to filter and organize.

## When to use it

Use this endpoint to build a tag picker that lets users create new tags on the fly, or to seed a starting set of tags when provisioning an organization.

## Related endpoints

- [Read Tag](/docs/API/read-tag) to list existing tags before creating a duplicate
- [Update Tag](/docs/API/update-tag) to rename a tag
- [Delete Tags (by IDs)](/docs/API/delete-tags-by-i-ds) to remove tags you no longer need
