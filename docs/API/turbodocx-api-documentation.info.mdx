The TurboDocx API lets you generate documents from your templates, send them for signature with TurboSign, and get notified with webhooks. Every endpoint page below shows its parameters, responses, request samples in seven languages, and a Try it console that calls the API with your own key.

## Base URL

All requests go to:

```
https://api.turbodocx.com
```

## Authentication

Every request needs two headers:

```
Authorization: Bearer YOUR_API_KEY
x-rapiddocx-org-id: YOUR_ORGANIZATION_ID
```

To get them:

1. Sign in to [TurboDocx](https://www.turbodocx.com), click your avatar, then **Settings**.
2. Open **API keys** (under **Developers**) to create or copy an API key. Keys start with `TDX-`.
3. Copy your organization ID from the **Features and integrations** page.

Keep your API key secret: never put it in client-side code or a public repository. A missing or invalid key returns `401 Unauthorized`, and a key whose role is not allowed to perform an action returns `403 Forbidden`.

## SDKs

Official SDKs for JavaScript and TypeScript, Python, PHP, Ruby, Go and Java wrap these endpoints. See [SDKs](/docs/SDKs) to install one.
